# ControlStock
Sistema web de control de inventario desarrollado con JavaScript.

## Funcionalidades

- Registro de productos.
- Validación de códigos SKU únicos.
- Control de cantidades disponibles.
- Registro básico de entradas y salidas de stock.
- Alertas de stock bajo.
- Búsqueda por nombre, código y categoría.
- Cálculo del valor estimado del inventario.
- Persistencia de datos en el navegador.

## Tecnologías

- HTML5
- CSS3
- JavaScript
- LocalStorage

## Cómo ejecutar el proyecto

1. Clonar o descargar el repositorio.
2. Abrir `index.html` en un navegador moderno.
3. Registrar productos desde el formulario.
